# 暗記アプリケーション

iPad と Apple Pencil で、**手書きで答えて自分で丸をつける**暗記アプリです。
選択肢や文字入力ではなく、実際に手で書いて覚えることを想定しています。

公開先: https://benkyouapuri.vercel.app/

---

## できること

- **手書き解答** — 画面全体がキャンバス。Apple Pencil の 240Hz サンプリングをそのまま使います
- **パームリジェクション** — ペンを検知したら指の接触を無視します。ペンより先に手のひらが触れてしまった線も、ペンが触れた時点で取り消します
- **自己採点** — 模範解答と解説を見て、自分で ⭕️ / ❌ を押します
- **間違えた問題の繰り返し** — 間違えた問題は、正解するまでその場で繰り返し出題されます
- **忘却曲線にもとづく出題順** — 最後に解いてからの経過時間と記憶の寿命から「いま思い出せる確率」を見積もり、確率の低い問題から出題します
- **スキマ時間向けの上限** — 「上位20問だけ」のように出題数を決められます。優先度の高い順に選ばれるので、**途中でやめてもそこまでが最善**です
- **問題集の管理** — 階層フォルダとタグで整理し、複数の問題集をまとめて出題できます
- **iPad から問題集を追加** — CSV を貼り付けるかファイルを選ぶだけ。パソコンは不要です

## 問題集は公開されません

問題集は教科書などをもとに作ることが多く、そのまま公開するわけにいきません。
そこで**アプリのコードと問題集を、置き場所ごと分けています。**

| | 置き場所 | 公開 |
|---|---|---|
| アプリのコード | このリポジトリ → Vercel | 公開 |
| 問題集のデータ | **別の非公開リポジトリ** | 非公開 |

問題集はデプロイに含まれないため、公開URLから直接読み取ることはできません。
取り出せるのは、合言葉を知っている人だけです。

GitHub のトークンは Vercel の環境変数にのみ存在し、ブラウザには一切渡りません。
ブラウザが持つのは合言葉だけです。

## 使い方

### 1. 合言葉を入れる

初回に一度だけ聞かれます。以後その端末では記憶されます。

### 2. 問題集を追加する

ホーム画面の「問題集を追加」から、次の3つを入力します。

| 項目 | 例 | 説明 |
|---|---|---|
| 保存先 | `世界史/近代/フランス革命` | スラッシュがそのまま階層になります |
| タグ | `世界史, 近代` | カンマ区切り。問題集ごとに付きます |
| 問題 | 下記のCSV | 貼り付けるか、ファイルから読み込みます |

CSV は **1列目が問題、2列目が答え、3列目が解説（任意）** です。

```csv
ルイ16世,フランス革命期の国王,1793年に処刑された
バスティーユ牢獄,1789年7月14日に襲撃された,革命の発端とされる
```

カンマを含む文には二重引用符が使えます。

```csv
"1789年7月14日,バスティーユ牢獄が襲撃された",フランス革命の発端,
```

### 3. 解く

ツリーから問題集を選び（複数可）、「選択した問題集で開始」を押します。
タグを選ぶと、そのすべてを持つ問題集だけに絞り込まれます。

**「出題する上限」に数を入れると、優先度の高い順にその数だけ出題されます。**
空いた時間に合わせて 5問・20問 と決められます。

出題画面では画面のどこにでも書けます。決定を押すと次の問題へ進み、
全問終わると丸つけに移ります。

### 出題の設定（歯車）

| 設定 | 既定 | 意味 |
|---|---|---|
| 正解したときの伸び | 2.5倍 | 正解すると記憶の寿命がこの倍率で延びます |
| 間違えたときに残す割合 | 20% | よく覚えていた問題ほど、間違えても間隔を長く保ちます |
| 間違えたときの最短間隔 | 30分 | 寿命がこれより短くはなりません |
| 何問ずつに区切るか | 0 | 長時間の勉強用。区切ると間違えた問題が早く戻ってきます |

## 自分で動かす場合

Node.js もビルドも不要です。

### 1. このリポジトリを Vercel に接続する

[vercel.com](https://vercel.com) でこのリポジトリを import します。
フレームワークの指定は不要です（静的サイト + `api/` のサーバー関数として動きます）。

### 2. 問題集用の非公開リポジトリを作る

GitHub で新しいリポジトリを **Private** で作成します。README を1つ入れておいてください
（完全に空だと最初の書き込みに失敗します）。

### 3. トークンを作る

GitHub の Settings → Developer settings → Personal access tokens → **Fine-grained tokens**

- Repository access: **Only select repositories** → 手順2で作ったリポジトリだけ
- Permissions → Repository permissions → **Contents: Read and write**

### 4. Vercel に環境変数を登録する

プロジェクトの Settings → Environment Variables に3つ登録します。

| Key | Type | 値 |
|---|---|---|
| `QUESTIONS_REPO` | Config | `ユーザー名/リポジトリ名` |
| `GITHUB_TOKEN` | Secret | 手順3のトークン |
| `APP_PASSPHRASE` | Secret | 自分で決めた合言葉 |

**合言葉が問題集を守る唯一の鍵です。**推測されにくい、十分に長いものにしてください。

登録後、再デプロイすると反映されます。

### 5. 確認する

`https://<あなたのURL>/api/health` を開くと、設定が揃っているかを返します。

```json
{ "ok": true, "repo_set": true, "token_set": true, "passphrase_set": true,
  "github": { "reachable": true, "private": true } }
```

`ok` が `false` のときは `hint` に原因が書かれています。

## 問題集のファイル形式

非公開リポジトリには、次の形で保存されます。

```
sets/世界史/近代/フランス革命.json
sets/英単語/システン/第1章.json
index.json
```

問題集1つ (`sets/<保存先>.json`):

```json
{
  "title": "フランス革命",
  "path": "世界史/近代/フランス革命",
  "tags": ["世界史", "近代"],
  "updated_at": "2026-08-31T09:00:00.000Z",
  "questions": [
    {
      "id": "mfk3x1-0",
      "question": "ルイ16世",
      "answer": "フランス革命期の国王",
      "commentary": "1793年に処刑された"
    }
  ]
}
```

一覧 (`index.json`) は保存のたびに自動更新されます。
パソコンから直接ファイルを置いた場合など、一覧がずれたときは
`/api/questions?rebuild=1` で作り直せます（合言葉が必要です）。

## 構成

```
index.html          画面
style.css           フォントと最小限のスタイル

script/state.js     共有する状態
script/dom.js       HTML の要素への参照
script/util.js      小さな道具（CSV解析など）
script/memory.js    記憶モデル（忘却曲線と寿命の更新）
script/api.js       合言葉とサーバーとの通信
script/progress.js  解答履歴
script/canvas.js    手書きキャンバスとペンの設定
script/quiz.js      出題・採点・画面の切り替え
script/library.js   問題集の一覧とツリー
script/upload.js    問題集の追加
script/app.js       起動処理

api/questions.js    問題集の読み書き（合言葉が必要）
api/health.js       設定の診断
```

ビルドは行わず、`index.html` が上の順番どおりに読み込みます。
**この順番には意味があります。**変数を宣言しているファイルより先に、それを使う
ファイルが実行されないよう並べてあります（`state` → `dom` → 各機能 → `app`）。
並べ替えるときは注意してください。

読み込みは `script/xxx.js?v=x.y.z` の形にしています。
**更新時は、画面下部に表示するバージョンと、すべての `?v=` を揃えて変更してください。**
これを忘れると、iPad が古いファイルをキャッシュから読み込みます。

### 開発時の注意

ローカルで動かす場合は、任意の静的サーバーで十分です。

```bash
python -m http.server 5173
```

ただし **`getCoalescedEvents()` は HTTPS でないと使えません。**
ローカルの `http://` では Apple Pencil の 240Hz が取得できず、60Hz 相当に落ちます。
**書き心地の検証は必ず HTTPS で行ってください。**
また `api/` のサーバー関数はローカルの静的サーバーでは動きません。
