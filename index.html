使い方

暗記アプリケーション

長期記憶アルゴリズム ＋ 短期記憶ループ学習

1. 学習の流れ

ホーム画面で問題集を選び、「選択した問題集で開始」を押します。

画面全体に手書きで答え、「決定」で次の問題へ進みます。全問書き終えると丸つけに移ります。

画面は真ん中の線で左右2ページに分かれていて、左のページから書いていきます。書ききれないときは、下のページ送りの「＋」でページを足せます。めくると1ページずつ進むので、右にあったページが左に移り、1つ前のページを見ながら続きを書けます。「‹」「›」で前後に行き来でき、丸つけのときも同じようにめくって見られます。

消去ボタンは、見えている2ページを消します。何も書いていないページの後ろにはページを足せず、白紙の最後のページは前に戻ると消えます。

模範解答と解説を見て、自分で ⭕️（合ってた）／ ❌（間違えた）を押します。

❌ を押した問題だけ、正解するまでその場で繰り返し出題されます。全問 ⭕️ になったら次のグループへ、なければホーム画面へ戻ります。

途中でやめたいときは、出題・丸つけの画面の左上の戻るボタンでホーム画面に戻れます。それまでに丸つけした問題の成績は保存されています。

2. どの問題から出るか（記憶予測）

最後に解いてからの経過時間と、問題ごとの「記憶の寿命」から、いま思い出せる確率を見積もります（忘却曲線）。

確率 = exp( −経過日数 ÷ 記憶の寿命 )

この確率が低い問題から順に出題されます。正解すると寿命が延びて出題が先延ばしになり、間違えると寿命が縮んで早く戻ってきます。一度も解いていない問題は確率0として最優先で出ます（未解答の問題どうしの中からは無作為に選ばれます）。

「出題する上限」を決めておくと、優先度の高い順にその数だけ出題されます。優先度順に選ぶので、途中でやめてもそこまでが最善になります。空いた時間の長さに合わせて、5問・20問のように決められます。

3. 問題集の追加（CSV / JSON）

ホーム画面の「問題集を追加」から、保存先（スラッシュで階層になります）・タグ・問題を入力します。問題は貼り付けるか、ファイルから読み込めます。ホーム画面に直接ファイルをドロップしても、この画面が開きます（1つずつ）。

CSV の場合

1列目が問題、2列目が答え、3列目が解説（省略可）です。

Apple,りんご,バラ科リンゴ属の果実。
Banana,バナナ,熱帯の多年生草本から採れる果実。

JSON の場合

見出しを鍵にした入れ子で書きます。出題するときは、見出しと問題が改行でつながって表示されます。CSV の「banana,バナナ」は「banana」とだけ表示されるので、類義語を答える問題集と一緒に出題すると何を答えればいいか分かりませんが、JSON なら「次の英単語の意味を答えなさい。」も一緒に表示されます。見出しは何段でも重ねられます。

{ "次の英単語の意味を答えなさい。": { "banana": "バナナ" }, "次の英単語の類義語を答えなさい。": { "look": "see" } }

答えを [答え, 解説] の配列にすると、解説も付けられます。

JSON は複数続けて貼れます（Gemini が問題集をパートに分けて出力したとき用）。別々の JSON に同じ見出しがあっても、問題は消えずに全部読み込まれます。

貼り付け欄・ファイルの中身が「{」で始まっていれば JSON、それ以外は CSV として読み取ります。判定結果はプレビューの先頭に [JSON] / [CSV] と表示されます。

穴埋め問題（JSON）

空欄を含む全文を見出しにして、その下に空欄の記号ごとの答えを書きます。全文を見せたまま、空欄1つずつが1問として出題されます。

{ "次の文の空欄に当てはまる語句を答えなさい。": { "酸化物から（1）を取り除く変化を（2）という。": { "（1）": "酸素", "（2）": "還元" } } }

空欄の記号は（1）・①・ア など自由ですが、数字だけ（"1"）にはしないでください。数字だけの記号は並び順が変わってしまいます。

4. ホーム画面の設定

長期記憶優先選出 … 確率の低い順に並べ替えます。OFFにすると問題集に入っている順のままです。

出題順をランダムにする … 選ばれた問題の中で、順番だけを入れ替えます。どの問題が選ばれるかは変わりません。

問題と答えを逆にする … 2列目（またはJSONの答え側）を問題として出します。

出題する上限 … 優先度の高い順に、その数だけ出題します（0で全部）。

何問ずつに区切るか … 長時間の勉強専用の設定です。区切ると、間違えた問題が早く戻ってきます。0なら一続きで出ます。

5. 歯車の設定（アルゴリズム設定）

正解したときの伸び … 正解すると記憶の寿命がこの倍率で延びます。

間違えたときに残す割合 … よく覚えていた問題ほど、間違えても間隔を長く保ちます。

間違えたときの最短間隔 … 寿命がこれより短くなることはありません。

6. 手書きについて

Apple Pencil を検知すると、以降ホーム画面に戻るまで指の接触を無視します（パームリジェクション）。ペンより先に手のひらが触れてしまった線も、ペンが触れた時点で取り消されます。

ペンを一度も使わなければ、そのまま指で描けます。ボタンは常に指でも押せます。

画面を回転すると、書いた内容は新しい画面の大きさに合わせて引き伸ばされます（線の形が縦横に伸び縮みします）。

試し書き

ペンで書くと、入力を1秒あたり何点受け取れているかが出ます。

本番と同じ描き方・同じペンの太さで描きます。Apple Pencil で約240点/秒なら、高頻度の入力がそのまま使えています。HTTPS で開いていないと約60点/秒に落ちます（ローカルの http:// など）。

出題の設定

最後に解いてからの経過時間で、いま思い出せる確率を見積もります。 確率の低い問題から順に出題されます。

大きいほど復習の間隔が早く延びます
